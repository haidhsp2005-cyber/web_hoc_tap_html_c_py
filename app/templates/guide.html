Hướng Dẫn Sử Dụng Hệ Thống Themis Edu

Nền tảng Web All-in-One hỗ trợ học tập, rèn luyện lập trình Web (HTML5/CSS3) và thuật toán (C++, Python 3) với cơ chế chấm điểm tự động chuẩn Themis, hiển thị công thức MathType/LaTeX và chấm lỗi cú pháp theo dòng.

Mục lục: 1. Tổng quan 2. Lập trình Web (HTML/CSS) 3. Thuật toán (C++ & Python) 4. Chế độ màn hình & Phím tắt 5. Dành cho Giáo viên (Up Themis)
1

Tổng Quan Về Nền Tảng Themis Edu

Themis Edu được thiết kế nhằm hiện đại hóa phương pháp dạy và học Tin học trong nhà trường phổ thông (đáp ứng chương trình GDPT 2018), giải quyết triệt để các hạn chế của phần mềm chấm offline truyền thống.

Chấm Tức Thì (Realtime)

Chấm bài tự động qua Cloud Engine siêu tốc; học sinh biết ngay kết quả điểm số (thang 10.0đ), lỗi cú pháp và từng test case đạt/chưa đạt.

Chấm Lập Trình Web Riêng Biệt

Báo chính xác lỗi đóng/mở thẻ theo dòng câu lệnh, kiểm tra cấu trúc DOM, hiển thị Live Preview trực quan ngay trong trình duyệt.

Nạp File ZIP Themis 1 Chạm

Giáo viên tận dụng 100% kho đề Themis sẵn có (.INP/.OUT trong Test01, Test02...) chỉ bằng cách nộp 1 file nén ZIP.

Hướng Dẫn Làm Bài Lập Trình Web (HTML5 & CSS3)

Chuyên đề Lập trình Web giúp học sinh làm quen với việc thiết kế trang web cá nhân, bảng thời khóa biểu, biểu mẫu và danh sách.

Bước 1: Chọn bài tập Web

Tại trang chủ, chọn chuyên đề "Lập trình Web - HTML & CSS Cơ bản" và bấm nút "Vào học & Làm bài".

Bước 2: Soạn thảo mã nguồn & Xem trước giao diện

Gõ mã HTML/CSS vào khung bên trái. Khung bên phải sẽ tự động hiển thị trang web trực quan (Live Preview). Bạn có thể bấm nút "Chạy Web" để cập nhật ngay lập tức.

Bước 3: Kiểm tra lỗi cú pháp theo dòng

Nhấn nút "Kiểm tra lỗi dòng": hệ thống sẽ quét từng thẻ HTML và báo rõ dòng mấy có thẻ chưa đóng hoặc sai thứ tự đóng lồng nhau.

Bước 4: Nộp bài chấm điểm

Nhấn nút "Nộp bài chấm điểm". Hệ thống sẽ tự động chuyển sang tab "Kết quả Chấm Điểm" và hiển thị chi tiết số điểm đạt được (tối đa 10.0đ) kèm danh sách tiêu chí DOM đã đạt/chưa đạt.

Hướng Dẫn Học & Chấm Thuật Toán (C++ & Python 3)

Áp dụng cho các chuyên đề cơ bản, rẽ nhánh, vòng lặp, mảng, số học và Quy hoạch động ôn thi HSG.

Cú pháp mẫu C++ (C++17 / GCC) 
#include <iostream>
using namespace std;

int main() {
    // freopen("BAI.INP", "r", stdin);
    // freopen("BAI.OUT", "w", stdout);
    long long a, b;
    if (cin >> a >> b) {
        cout << a + b << endl;
    }
    return 0;
}
Cú pháp mẫu Python 3.14 
import sys

def main():
    data = sys.stdin.read().split()
    if not data:
        return
    a, b = int(data[0]), int(data[1])
    print(a + b)

if __name__ == '__main__':
    main()
Tính năng Chạy thử với dữ liệu tự chọn (Custom Input):

Trước khi nộp bài chính thức, bạn có thể chuyển sang tab "Dữ liệu vào (Input)", nhập bất kỳ dữ liệu thử nghiệm nào và nhấn "Chạy thử" để xem chương trình in ra gì, kiểm tra độ chính xác mà không bị trừ điểm.

Tốc độ chấm điểm siêu tốc qua Godbolt Compiler Explorer:

Khi nhấn "Nộp bài chấm điểm", hệ thống kích hoạt công nghệ chấm song song đa luồng qua máy chủ GCC 13.2 (-O2), chấm toàn bộ 10 test Themis chỉ trong 1.5 đến 2.5 giây, phát hiện lỗi biên dịch trong 0.6 giây.

Chế Độ Hiển Thị Màn Hình & Phím Tắt Tiện Ích

Chế độ chuyển đổi giao diện:

  • Khung Code Đầy Đủ (100% Full Width): Mở rộng tối đa không gian soạn thảo mã nguồn, ẩn khung xem trước để học sinh tập trung lập trình.
  • Chia đôi 50:50: Hiển thị song song cả trình soạn thảo code và khung xem trước/bảng điểm. Có thể kéo thanh trượt ở giữa để dãn rộng linh hoạt.
  • Xem Web: Phóng to toàn bộ màn hình kết quả trang web để kiểm tra trực quan.

Bảng phím tắt hữu ích:

Phím tắt Chức năng
Ctrl + Space Bật gợi ý gõ code thông minh (IntelliSense)
Ctrl + / Bật / Tắt ghi chú dòng mã (Comment)
Ctrl + Z / Ctrl + Y Hoàn tác (Undo) / Làm lại (Redo)
Ctrl + F Tìm kiếm và thay thế trong mã nguồn

Dành Cho Giáo Viên & Quản Trị Đề Bài (Up Themis)

Giáo viên có thể dễ dàng khởi tạo đề bài mới, thiết lập giới hạn thời gian, công thức toán học và nạp nguyên bộ Test Themis chỉ với 1 thao tác kéo thả.

Cấu trúc file ZIP Themis chuẩn:

File ZIP có thể nén trực tiếp các thư mục con Test01, Test02, ..., Test10: 

BAI_TAP.zip
├── Test01/
│   ├── BAI_TAP.INP
│   └── BAI_TAP.OUT
├── Test02/
│   ├── BAI_TAP.INP
│   └── BAI_TAP.OUT
└── ...

Hệ thống tự động nhận diện tên file INP/OUT không phân biệt hoa thường.

Hỗ trợ công thức Toán học MathType & LaTeX:

Khi nhập nội dung đề bài, giáo viên có thể chèn công thức toán học dễ dàng:

  • Công thức trong dòng: $1 \le N \le 10^5$
  • Công thức phân số: $\frac{a + b}{2}$
  • Độ phức tạp thuật toán: $O(N \log N)$
  • Khối công thức hiển thị riêng: $$S = \sum_{i=1}^N A_i$$

Công nghệ KaTeX & MathJax 3 được tích hợp sẵn sẽ tự động render công thức sắc nét!
